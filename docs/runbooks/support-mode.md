# Support mode

RULES 6.8: time-boxed, reason-required, phone numbers masked, un-masking separately logged.

## Do

1. Console → salon → **Support** → *Start support session*: the ticket or reason, and a length
   (60 minutes by default, 120 at most).
2. A red banner shows the salon, the end time and the reason for as long as it runs.
3. Search by the first letters of a name or the **last four digits** of a number. Numbers show as
   `•••••• 4821`.
4. Need the whole number (to call them back)? **Show number** - with its own reason. Each one is a
   separate audit entry.
5. **End session now** when done. It also ends by itself at the time box.

## Never

- Share a screen with a session open.
- Copy data out of the console into a ticket, a chat or a spreadsheet. Write what you did, not what
  you saw.
- Use support mode to look someone up for a reason that is not the ticket.
